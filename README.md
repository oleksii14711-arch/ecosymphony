# ЕКОСИМФОНІЯ — жива екосистема зі звуку

Інтерактивний експонат: темний біолюмінесцентний сад, який ви вирощуєте звуком
і який у відповідь створює власну музику.

Цикл: **зовнішній звук → зміни екосистеми → поведінка істот → музика світу.**

## Як відкрити

Найпростіше: відкрийте файл **`dist/index.html`** подвійним кліком — усе
(код і стилі) вбудовано в один файл, інтернет не потрібен.

Або для розробки: `npm install`, потім `npm run dev`.

## Перші 30 секунд

1. Світ одразу живий у німому деморежимі.
2. Натисніть **«Оживити світ»**, потім оберіть: **Демонстрація** (звук генерується
   програмно), **Мікрофон** або **Мій аудіофайл**.
3. Дозвіл на мікрофон питається лише після вибору «Мікрофон». Відмова не блокує
   гру — увімкнеться запасний тихий аналіз, світ житиме далі.

## Правила звуку (є і в довідці всередині)

- **Низькі частоти** живлять 🌰 кореневиків → вони створюють бас.
- **Середні частоти** ведуть ✨ світляків → ті співають короткі ноти (пентатоніка).
- **Високі частоти й різкі атаки** будять ⚡ іскор → ті дають перкусію.
- **Тиша** — стан спокою: витрати енергії падають, частина істот дрімає.
  Коротка пауза світ не вбиває; зниклий вид повертається зі спор.

## Інструменти

- 🍯 **Їжа** — клік залишає енергетичну пляму.
- 🌊 **Течія** — проведіть вказівником, потік понесе істот.
- 🛟 **Притулок** — клік створює тимчасову захищену зону (повільніше виснаження).

## Дві долі одного світу

Кнопка **«⑂ Розділити долю»** клонує світ у долі А (без змін) і Б (з одним
втручанням: більше їжі / тривала тиша / сильніша течія). Обидва світи крокують
з однаковим фіксованим кроком і незалежними генераторами випадковості.
Перемикач «чути» обирає, який світ озвучується. Стрічка порівняння показує
лише фактичні показники (популяція, покоління, середні ознаки).

## Збереження

- 💾/📂 — зберегти / відновити у браузері.
- ⬆/⬇ — експорт / імпорт JSON (перевіряється версія формату; чужий файл відхиляється з поясненням).
- 📷 — знімок PNG поточного видимого світу.
- 🌱 — «Насіння світу» (код виду `ECO-XXXXXX-X`). Чесне зауваження: насіння
  відтворює лише початкові умови, а не історію ваших дій чи аудіо.
- Журнал фіксує перші народження, нові покоління та зникнення видів.

## Техніка

TypeScript + Canvas 2D + Web Audio API (процедурний синтез, без зовнішніх
сервісів і ключів). Симуляція відокремлена від рендеру й аудіо, фіксований крок
1/30 с, просторова сітка сусідів, жорстка межа 300 істот. Внутрішня музика
ніколи не подається назад в аналізатор входу; мікрофон не підключено до
колонок (захист від свисту) + автоматичне приглушення при перевантаженні.
У прихованій вкладці симуляція й звук стають на паузу без стрибка часу.

Кнопка 🍃 — ручний екорежим (менше ефектів); за низького FPS ефекти
знижуються автоматично.

## Перевірено

- `npm test` — 9 тестів: інваріанти енергії/координат, межа популяції, тиша не
  вбиває світ, помірний темп росту, детермінізм насіння, збереження/відновлення,
  незалежність клонів, дія інструментів, відхилення невірної версії.
- `npm run build` — чиста збірка в один `dist/index.html`.
- Браузер (headless Chromium): стартовий екран → «Оживити світ» → демонстрація
  (рахунки ростуть, журнал пише), інструмент їжі, розділення долі (два канваси,
  порівняння), збереження/відновлення, мобільний вигляд 390px, відмова
  мікрофона (запасний режим), непідтримуваний файл (чітка помилка, гра не
  блокується), відкриття через file:// — усе без помилок у консолі.

## Обмеження (чесно)

- **Фізичний мікрофон і реальні колонки не перевірені** — немає доступу до
  аудіопристроїв у цьому середовищі; аналіз перевірено синтетичним сигналом
  (демо-генератор через той самий FFT-тракт) та запасним режимом.
- **Продуктивність на вашому Xeon W3565 не вимірювалась** — ціллю є 150–300
  істот; є авто- й ручне зниження ефектів, але старий ПК треба перевірити вручну.
- Звук можна оцінити лише вухом на реальному пристрої — скриншоти цього не доводять.
